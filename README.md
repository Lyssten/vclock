# vclock

Вертикальные часы для терминала в стиле [`tty-clock`](https://github.com/xorg62/tty-clock), но с раскладкой **стопкой**: часы, минуты и секунды идут друг под другом, а не в ряд. Цифры рисуются сплошными блоками `█` подлинным 3×5 шрифтом tty-clock.

```
    ██  ██████      ← часы
    ██      ██
    ██      ██
    ██      ██
    ██      ██
   ██    ██         ← двоеточие-разделитель
██████  ██████      ← минуты
    ██      ██
██████  ██████
██      ██
██████  ██████
   ██    ██
██████  ██████      ← секунды
    ██      ██
██████  ██████
██          ██
██████  ██████

  15-06-2026     ← дата (-d)

  CPU 10% 53°C   ← нагрузка+температура CPU (--cpu --temp)
  GPU 36% 56°C   ← нагрузка+температура GPU (--gpu --temp)
  ▄▃▂▂▁▁▁▁▁▁     ← загрузка по ядрам (--cores)
  4.0 W          ← мощность SoC (--power)
  utun4          ← имя сетевого интерфейса (--net utun4)
  ↓ 38.8 KB/s    ← входящая скорость
  ↑ 296.3 KB/s   ← исходящая скорость
```

Всё выводится **стопкой** и **не шире блока цифр** (≤14 символов). Нагрузка и температура
объединяются в одну строку; `--cores` рисует по символу `▁▂▃▄▅▆▇█` на каждое ядро.

## Зачем

Горизонтальные `HH:MM:SS` неудобны в узких вертикальных панелях (tmux, сайдбар). Готового нативного аналога со стопкой не существует — все терминальные часы (tty-clock, clock-rs, tock, peaclock, tetrotime) рисуют время в ряд. `vclock` закрывает эту нишу.

## Требования

- Python 3 (есть в системе по умолчанию на macOS/Linux)
- Терминал с поддержкой Unicode и ANSI-цветов (любой современный)

Для часов внешних зависимостей нет — один файл. **Блок метрик** (`--cpu/--gpu/--temp/--power`)
требует [`macmon`](https://github.com/vladkens/macmon) — sudoless-монитор для Apple Silicon:

```bash
brew install macmon
```

`--net` и `--cores` работают без macmon: сеть — через `netstat`, загрузка по ядрам — через
`host_processor_info` (ctypes, без зависимостей). Метрики рассчитаны на macOS Apple Silicon
(M-серия).

## Установка

```bash
git clone <этот-репозиторий> vclock
cd vclock
# вариант 1: положить в PATH
cp vclock ~/.local/bin/vclock      # убедись, что ~/.local/bin в $PATH
# вариант 2: запускать напрямую
./vclock
```

## Использование

```bash
vclock                 # часы со секундами и двоеточием, по центру экрана
```

Выход — `Ctrl+C` (курсор и экран восстановятся).

## Флаги

### Часы

| Флаг        | Описание                                                                 |
|-------------|--------------------------------------------------------------------------|
| `-c ЦВЕТ`   | Цвет цифр, номер палитры ANSI-256. По умолчанию `51` (cyan).              |
| `-s`        | Без секунд — показывать только часы и минуты.                             |
| `--12`      | 12-часовой формат вместо 24-часового.                                     |
| `-b`        | Мигающее двоеточие (раз в секунду).                                       |
| `-d`        | Показать дату `dd-mm-yyyy` мелким шрифтом внизу.                          |
| `-n`        | Без центрирования узких цифр — выравнивание по ячейке, как в tty-clock.   |
| `-h`        | Справка.                                                                  |

### Метрики (под датой)

Каждая метрика включается своим флагом и выводится приглушённым текстом под часами.

| Флаг            | Описание                                                      | Источник   |
|-----------------|---------------------------------------------------------------|------------|
| `--cpu`         | Загрузка CPU, %. С `--temp` — в одной строке: `CPU 10% 53°C`. | macmon     |
| `--gpu`         | Загрузка GPU, %. С `--temp` — в одной строке: `GPU 36% 56°C`. | macmon     |
| `--temp`        | Температуры CPU и GPU, °C (добавляются к строкам CPU/GPU).     | macmon     |
| `--cores`       | Загрузка по каждому ядру спарклайном `▁▂▃▄▅▆▇█` (1 символ/ядро).| ctypes    |
| `--power`       | Энергопотребление SoC, Вт                                     | macmon     |
| `--net [ИФЕЙС...]` | Скорость сети ↓/↑ по интерфейсам + их имена. Без значения — дефолтный маршрут; можно несколько — каждый отдельным блоком (напр. `--net utun4 ppp0`). | `netstat` |

Метрики собираются в фоне (отдельные потоки) и обновляются **раз в 5 секунд**, чтобы не
нагружать систему; секунды на часах при этом тикают каждую секунду. При выходе фоновые
процессы корректно завершаются.

### Сеть и VPN/прокси (`--net`)

`--net` без значения берёт интерфейс маршрута по умолчанию (обычно `en0`). Чтобы видеть
скорость **через VPN/туннель**, укажи его интерфейс — например `--net utun4`. Можно перечислить
**несколько** — каждый покажется отдельным блоком (имя + ↓/↑):

```bash
vclock -d --net utun4 ppp0 en0     # три интерфейса по отдельности
```

```
utun4              ppp0               en0
↓ 1.9 KB/s         ↓ 2.8 KB/s         ↓ 5.7 KB/s
↑ 1.5 KB/s         ↑ 960 B/s          ↑ 4.0 KB/s
```
(в часах блоки идут стопкой друг под другом, здесь — рядом для наглядности)

Список своих интерфейсов с трафиком:

```bash
netstat -ib | awk '$3 ~ /^<Link/ && ($7+$10)>0 {print $1}'
ifconfig | grep -E '^(utun|ppp|ipsec)'   # туннели VPN
```

Имя выбранного интерфейса показывается заголовком над ↓/↑. Оговорка: так считается трафик
**сетевого интерфейса**. Обычный HTTP/SOCKS-прокси без отдельного tun-интерфейса делит `en0`
с остальным трафиком и отдельно не выделяется — для него измерить «скорость через прокси»
по интерфейсу нельзя.

### О флаге `-n` (центрирование)

В шрифте tty-clock цифра `1` занимает только правый столбец ячейки. Поэтому пара вроде `17` визуально «жмётся» вправо относительно `23`. По умолчанию `vclock` центрирует каждое число **по реальным закрашенным пикселям**, чтобы все строки стояли на одной оси симметрии:

```
центрирование ВКЛ (по умолчанию)      центрирование ВЫКЛ (-n)
  ██  ██████                            ██  ██████
  ██      ██                            ██      ██
```

Флаг `-n` возвращает «сырое» выравнивание по ячейке (поведение как в оригинальном tty-clock).

### Цвета (`-c`)

Принимается номер из палитры ANSI-256 (0–255). Частые значения:

| Номер | Цвет      |
|-------|-----------|
| `51`  | cyan (по умолч.) |
| `46`  | зелёный   |
| `196` | красный   |
| `201` | маджента  |
| `226` | жёлтый    |
| `33`  | синий     |
| `15`  | белый     |

## Примеры

```bash
vclock -d                 # часы + дата внизу
vclock -d -b              # + мигающее двоеточие
vclock -d -c 46           # зелёные цифры
vclock -s -d              # без секунд, с датой
vclock --12 -d            # 12-часовой формат
vclock -n                 # выравнивание по ячейке (как tty-clock)
vclock -c 201 -b -d       # маджента, мигание, дата — всё вместе

# с метриками (нужен macmon для cpu/gpu/temp/power):
vclock -d --cpu --gpu --temp               # дата + нагрузка и температуры одной строкой
vclock -d --cores                          # загрузка по ядрам спарклайном
vclock -d --cpu --temp --net utun4         # CPU+°C и скорость через VPN-туннель utun4
vclock -d --net utun4 ppp0                 # два туннеля по отдельности
vclock --net ppp0                          # только скорость через ppp0, без macmon
vclock -s -d --cpu --gpu --temp --cores --power --net   # всё сразу
```

### Отдельный монитор

`macmon` сам по себе — красивый sudoless-монитор Apple Silicon (CPU/GPU/ANE, мощность,
температуры, память). Запусти просто `macmon` для полноценного TUI; `vclock` использует
его `pipe`-режим лишь как тихий источник чисел под часами.

### Алиас (необязательно)

Чтобы запускать одной короткой командой, добавь в `~/.zshrc` или `~/.bashrc`:

```bash
alias clock='vclock -d'
```

## Как это работает

- Цифры заданы битовой картой 3×5 (15 бит на знак) — это подлинный шрифт tty-clock.
- Каждый «включённый» пиксель рисуется двумя блоками `██` для квадратности.
- Кадр перерисовывается ~5 раз в секунду, экран не мигает (курсор скрыт, обновление через `\033[H`).
- Центрирование по экрану и по оси чисел считается на лету и подстраивается под размер терминала.
- Метрики читаются в фоновых потоках (опрос раз в 5 сек): `macmon pipe` (JSON-поток) для
  CPU/GPU/температур/мощности, `host_processor_info` для загрузки по ядрам, `netstat -ib` для
  скорости сети — всё без sudo.

## Планы

Сейчас метрики работают на **macOS Apple Silicon**. Сами часы (рисование цифр, раскладка)
платформонезависимы — там только ANSI и стандартная библиотека. В планах — версия для **Linux**
(источники метрик через `/proc`, `/sys`, `lm-sensors`, `nvidia-smi`).
